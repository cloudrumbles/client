# Native browser terrain generation

This module calls Pumpkin's original Rust biome, density/noise and surface stages inside a dedicated WASM Worker. The exact pin is `70b31323967bb99fd4feefab8e96124be369cd6f`, which targets Minecraft **1.21.11** and is licensed **MIT**. That historical pin predates current Pumpkin's GPL license; `Pumpkin.LICENSE` preserves its exact notice. The client wrapper uses the client repository's license. No Minecraft JAR, textures, decompiled Java or private worlds are distributed.

The included upstream archive is the exact GitHub source snapshot, with SHA-256 `a58c0ac04e2f097d5ffe6f85cba3f1360a17bcdd0de12c6e7fd4fea532cc43a8`. `browser-platform.patch` contains every change. Native file I/O stays on Tokio; the WASM compilation seam uses RAM file interfaces, excludes OS-thread constructors and packs heightmap words with `u64`. The generation exports themselves never read or write these RAM files. Actual saved columns use the client's bounded IndexedDB `ChunkStore` and existing local lighting worker.

One correctness fix replaces the upstream surface RNG cache's allocation-address key with the random generator's value. Otherwise, generating a new seed at a reused address can retain a prior world's bedrock random stream. A worker retains one generator for its world, one active protochunk and one extracted result. Queue length is bounded; cancellation of an indivisible Rust stage terminates the worker. Exact signed 64-bit seed, dimension, version, world identity and epoch guards prevent results from a previous world reaching the current world. Generated numeric state IDs are translated by exact native block name/properties and biome names; incompatible registries are rejected.

## Build

Run `node generation/build.mjs` from the browser project. Verified checked-in artifacts avoid an unnecessary rebuild; `node generation/build.mjs --rebuild` compiles the corresponding source. `--prepare-only` extracts and patches it for inspection. Building requires Rust stable with `wasm32-unknown-unknown`, Git, tar and wasm-bindgen **0.2.129**. Set `WASM_BINDGEN` to that executable if it is not on PATH. If absent, the build installs that exact version under `generation/target/tools`. The lockfile retains the pinned server dependency versions. All extracted source, tool and compiler caches remain under `target/` and are excluded from distribution.

`pkg/BUILD.json` records input and artifact hashes. Reproduction compares the generated terrain against `native-vectors.json`, emitted by the original native Rust stages in isolated processes. These checks prove browser/native Pumpkin agreement; they do not prove vanilla Java terrain parity.

## Current scope

Overworld, Nether and End **biomes, noise and surface** are admitted. Trees, ores, decoration, carvers and completed structures are not admitted yet. At this pin, upstream's feature stage still iterates unordered feature maps with TODO biome/step seed ordering, and structure references are unfinished. Those methods cannot be represented as vanilla-correct finished world generation. The browser terrain mode must identify this scope to players; imported Java worlds and the native service remain available.

Generation timing describes this worker on the current test CPU, not gameplay FPS or a GTX 1650 Ti result. Native Rust phases are indivisible and can exceed the worker's target phase budget; they are isolated from rendering and yield between phases.

The production **Browser terrain** form is an explicit mode choice; the existing demo still starts by default. A generated world receives a separate persistent identity, exact signed-long seed and clock, native dimension type, saved location, local block authority, inventory and ground items. Resume restores stored columns and edits before generating missing columns. Spawn waits for its known column and chooses an empty dry space with a collision floor. Native Nether and End world bounds are 0–255; their 128-block generation noise shapes do not shorten the playable dimension. A matching user-supplied 1.21.11 JAR supplies original assets, items and crafting definitions.

Run `node --test tests/source-generation.test.mjs tests/source-world-state.test.mjs` for native differential, failure and persistence checks. `node tests/browser.source-generation.mjs` exercises actual dedicated workers, cancellation, saved columns and local lighting without a GPU. With the development server running, `POMME_SOFTWARE_GPU=1 node tests/browser.source-generation-main.mjs` exercises the production UI, inventory/item transfer, full reload/resume and all three dimensions on Chromium software WebGPU. Set `POMME_MINECRAFT_JAR` to a private original 1.21.11 client JAR to repeat that check with original assets. These browser checks explicitly record that target Nvidia hardware was not verified.
